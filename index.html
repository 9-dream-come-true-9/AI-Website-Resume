项目介绍

个人开源项目 · 招聘自动化

BOSS 直聘 Windows 桌面端 AI 智能体 Skill 合集

查看 GitHub 项目 ↗

面向 BOSS 直聘 Windows 桌面端，提供岗位发布、候选人初评分、批量及定向沟通、简历索要与收取能力。 4 个可组合 Skill 可独立安装，也可按招聘流程组合调用。

  1. 01

    岗位发布

    支持 4 类岗位，填写并核验职位、JD、薪资、学历等字段后发布。

  2. 02

    候选人初评分

    读取岗位 JD 与消息页候选人资料，输出匹配分数、依据与信息缺口。

  3. 03

    候选人沟通

    支持批量打招呼、文档回复、批量消息与指定联系人发送。

  4. 04

    简历索要与收取

    支持平台或消息索要简历，下载 PDF / DOCX 后完成校验与解析。

岗位发布支持实习、社招全职、应届校招和兼职 4 类岗位，填写职位名称、工作内容、薪资、学历等信息后发布。

候选人筛选根据岗位要求给候选人评分，说明匹配理由，并标出还需要了解的信息。

消息与简历可以批量或单独联系候选人，索要、接收和读取 PDF 或 Word 简历。

非 BOSS 直聘官方项目。
